# Olá! Sou profissional de Dados e AI Builder 👋

Sou formado em Ciência de Dados e tenho experiência conectando tecnologia, inteligência artificial e necessidades de negócio para construir soluções que simplificam processos e geram impacto.

Minha atuação combina análise de dados, automação de processos, desenvolvimento de ferramentas e aplicação de IA generativa.
